# Friuli 2026

Vikend 10.–11. listopada 2026: Muggia, Udine, Cividale del Friuli i Duino.
Dino, Dolores, Krešo i Jelena.

**Karta:** https://dinom-lab.github.io/friuli-2026/

## Plan

**Subota:** Zagreb → Muggia (ručak, lučica, gelato) → Udine (Castello za zalazak sunca, tajut na Piazzi Matteotti, večera u Osteriji Alla Ghiacciaia) i noćenje.

**Nedjelja:** Cividale (Ponte del Diavolo, Tempietto Longobardo, Festa della Zucca ako je taj dan, ručak u Antico Leon d'Oro) → Castello di Duino i Rilkeova staza → Ipercoop Montedoro → Zagreb oko 21:30.
